# 100yd Sync

ゴルフのラウンド記録＆自己修正アプリ（スマホ・PWA・オフライン動作）。

- 単一 `index.html`（フレームワーク無し・外部通信ゼロ）。
- 記録データは**端末内（localStorage）のみ**に保存されます。サーバーやこのリポジトリには送信・保存されません。
- HTTPS配信（GitHub Pages）＋Service Workerにより、ホーム画面に「インストール」でき、インストール後は**完全オフライン**で単体アプリとして動作します。

## Pixel 等 Android へのインストール
1. Chromeで公開URLを開く
2. 右上「⋮」→「アプリをインストール」（または「ホーム画面に追加」）
3. ホーム画面のアイコンから起動（ブラウザ枠なし・オフライン可）
